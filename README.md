# blogAPP

Projeto de blog desenvolvido com Node.js, Express, MongoDB e Handlebars.

O objetivo do projeto foi praticar conceitos de desenvolvimento web full stack, incluindo autenticação de usuários, gerenciamento de conteúdo e controle de acesso administrativo.

## Tecnologias utilizadas

* Node.js
* Express
* MongoDB
* Mongoose
* Handlebars
* Bootstrap 5
* Passport.js
* Bcrypt.js
* Express Session
* Connect Flash

## Funcionalidades

* Cadastro de usuários
* Login e autenticação
* Criptografia de senhas
* Controle de acesso por administrador
* Cadastro de categorias
* Cadastro de postagens
* Edição e remoção de postagens
* Listagem de postagens por categoria
* Área administrativa para gerenciamento do conteúdo

## Instalação

Clone o repositório:

```bash
git clone https://github.com/nsschroder/blogAPP.git
```

Instale as dependências:

```bash
npm install
```

Configure o MongoDB localmente e inicie a aplicação:

```bash
npm start
```
